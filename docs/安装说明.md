# 安装说明

本文档详细说明如何从零开始部署和运行"个人天赋发掘测评系统"。

---

## 1. 环境要求

| 项目 | 最低版本 | 说明 |
|------|----------|------|
| Python | 3.10+ | 推荐 3.12+，项目开发使用 3.14.0 |
| pip | 最新版 | 随 Python 自带 |
| 操作系统 | macOS / Linux / Windows | 三平台均可运行 |
| 浏览器 | Chrome 90+ / Firefox 88+ / Safari 15+ | 需支持 ES6+ 和 CSS 变量 |

> 不需要安装 Node.js、数据库服务器或其他额外软件。

---

## 2. 获取源代码

```bash
git clone https://github.com/Mistakeman56/talent-excavator.git
cd talent-excavator
git checkout develop
```

或者直接下载 ZIP 压缩包解压。

---

## 3. 创建虚拟环境

```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Windows CMD
python -m venv .venv
.venv\Scripts\activate
```

激活后终端提示符会出现 `(.venv)` 前缀。

---

## 4. 安装依赖

```bash
pip install -r requirements.txt
```

安装完成后可验证：

```bash
pip list | grep -i flask
```

应看到 `Flask`、`Flask-Login`、`Flask-SQLAlchemy` 三个包。

---

## 5. 配置环境变量

### 5.1 复制模板

```bash
cp .env.example .env
```

### 5.2 编辑 `.env` 文件

用任意文本编辑器打开项目根目录下的 `.env` 文件：

```env
# Flask 安全密钥（必填，生产环境请使用强随机字符串）
SECRET_KEY=your-strong-secret-key-here

# AI 提供商：deepseek 或 kimi
PROVIDER=deepseek

# DeepSeek API 密钥（默认使用，必填）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx

# Moonshot (Kimi) API 密钥（可选，切换到 kimi 时需要）
KIMI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

### 5.3 获取 API 密钥

| 提供商 | 注册地址 | 说明 |
|--------|----------|------|
| DeepSeek | https://platform.deepseek.com/ | 默认使用，性价比高 |
| Moonshot (Kimi) | https://platform.moonshot.cn/ | 可选，通过 `PROVIDER=kimi` 切换 |

注册后在对应平台的"API 密钥"页面创建密钥，复制到 `.env` 文件中。

### 5.4 生成安全密钥（可选）

`SECRET_KEY` 用于 Flask 的 session 加密。可以用以下命令生成一个随机密钥：

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

将输出的字符串填入 `.env` 的 `SECRET_KEY` 字段。

## 6. 启动服务

### 6.1 开发模式

```bash
python app.py
```

首次启动时系统会自动：

1. 创建 SQLite 数据库文件 `instance/talent_assessment.db`
2. 创建所有数据表
3. 创建默认管理员账号（用户名 `op`，密码 `323328`）
4. 导入 Human 词典数据

启动成功后终端会显示：

```
* Running on http://0.0.0.0:5001
```

在浏览器中访问 `http://localhost:5001` 即可使用。

### 6.2 生产模式（Gunicorn）

项目已内置 Gunicorn 配置文件，可直接使用：

```bash
gunicorn -c gunicorn.conf.py app:app
```

配置说明（`gunicorn.conf.py`）：
- 绑定地址：`127.0.0.1:5001`（仅本地监听，由反代对外暴露）
- Worker 数量：4 个
- 超时时间：120 秒（AI 访谈接口可能较慢）
- 最大请求数：2000（自动重启防内存泄漏）

### 6.3 systemd 自启动（Linux 服务器）

项目提供了 systemd 服务模板 `deploy/talent-app.service`：

```bash
# 复制服务文件
sudo cp deploy/talent-app.service /etc/systemd/system/

# 重载配置
sudo systemctl daemon-reload

# 启用并启动
sudo systemctl enable --now talent-app

# 查看状态
sudo systemctl status talent-app

# 查看日志
sudo journalctl -u talent-app -f
```

> 使用 systemd 前请确保已将项目部署到 `/opt/talent-app` 目录，或修改服务文件中的路径。

## 7. 常见问题

### 7.1 `ModuleNotFoundError: No module named 'flask'`

虚拟环境未激活，或依赖未安装。执行：

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### 7.2 `ValueError: SECRET_KEY must be set`

`.env` 文件不存在或 `SECRET_KEY` 为空。检查：

1. 项目根目录下是否有 `.env` 文件
2. `SECRET_KEY` 是否已填写

### 7.3 `ValueError: DEEPSEEK_API_KEY must be set`

API 密钥未配置。检查 `.env` 文件中对应提供商的密钥是否已填写。

### 7.4 端口被占用

如果 5001 端口被占用，可以修改 `.env` 文件：

```env
FLASK_PORT=5002
```

然后重新启动。

### 7.5 数据库重置

如果需要重置所有数据，删除数据库文件后重启即可：

```bash
rm instance/talent_assessment.db
python app.py
```

系统会自动重新创建数据库和导入词典数据。

### 7.6 Windows 下 `python3` 命令不存在

Windows 下使用 `python` 代替 `python3`。

## 8. 反向代理配置

生产环境建议使用反向代理（Nginx / Lucky 等）对外暴露服务，并配置 SSL 证书。

### 8.1 使用 Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate     /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:5001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 8.2 使用 Lucky 反代

1. 在 Lucky 中添加反代规则，目标地址设为 `内网IP:5001`
2. 开启 SSL（支持 Let's Encrypt 自动申请证书）
3. 路由器/光猫上将 80 和 443 端口转发到 Lucky 所在机器
